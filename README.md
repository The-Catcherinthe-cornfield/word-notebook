# 单词记录本 Word Notebook

用 Python + tkinter 写的桌面单词记录本。

目标：每天录入新学的单词，按遗忘曲线提醒复习，点一下单词就能看到释义。

> 当前进度：**v0** —— 窗口和交互的起点

## 现在能做什么

- 打开一个 500×500 的窗口
- 输入英文单词，点「添加」就出现在下面的列表里
- 输入为空时会提示"请输入单词"

## 怎么运行

```bash
python v0.py
```

tkinter 是 Python 自带的标准库，Windows 下不需要额外安装。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `v0.py` | 第一个能跑的窗口版本：输入框 + 添加按钮 + 列表 |
| `lesson.py` | SQLite 学习代码：建库、建表、确认数据库文件生成 |

## 代码要点（v0）

- `root = tk.Tk()` 创建主窗口；`root.mainloop()` 必须写在最后
- `tk.Entry` 是输入框，`tk.Button(command=...)` 绑定点击函数，`tk.Listbox` 是列表
- `word_entry.get()` 取输入内容，`delete(0, tk.END)` 清空输入框
